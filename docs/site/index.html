What this record does not claim

A validation record that only shows what passes is not a validation record.

–This is a public reference dataset, not the Alice Springs / DKP pilot data — that still requires written commercial-use permission (data_pipeline/sources.json) and is Sprint 1 of the rollout.
–The energy-balance pass rate validates the sign-convention / unit-conversion code path against the meter identity; this public dataset has no independent redundant metering to test against.
–PV and BESS recall are measured by injecting synthetic, fixed-seed faults into real held-out telemetry — not real labelled incidents.
–The BESS "state of charge" is an indicative index derived from real charge/discharge energy, not an OEM SOC signal.
–The 24-hour forecast horizon is below the coverage target in this backtest — a concrete, scoped item for the pilot phase.

Reproduce this record

Deterministic given the same input files (fixed random seed for fault injection). Inputs are re-downloadable and checksum-verifiable from the URLs above.

# real data in data_raw/ -> data_processed/reference_2016/backtest_report.json
python data_pipeline/reference_backtest.py
# backtest_report.json -> lib/reference-dataset.ts (feeds every product page)
python data_pipeline/generate_reference_ts.py
# confirms the product still builds and all tests pass on the regenerated data
pnpm run build && pnpm test
# deep-learning forecaster, trained/evaluated on the same real fixed split
python data_pipeline/deep_forecast.py
# C++ edge collector — build with CMake + Ninja, run the 3 ctest suites
cmake -S edge-collector-cpp -B edge-collector-cpp/build -G Ninja && cmake --build edge-collector-cpp/build && ctest --test-dir edge-collector-cpp/build
# Java BMS connector — plain javac/java build, no Maven/Gradle
powershell bms-connector-java/scripts/build-and-test.ps1
